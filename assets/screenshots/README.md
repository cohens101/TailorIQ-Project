# Screenshot guidelines

This public showcase intentionally does not publish personal applicant resumes or obsolete development screenshots.

To add product screenshots later, capture the current production site using **entirely fictional** resume and job-description content. Verify that browser tabs, addresses, API keys, names and contact details belonging to real people are not visible. Add image files under `assets/screenshots/` and link to them in the root README.

The workflow illustration in `assets/visuals/` is conceptual, not a production screenshot.
